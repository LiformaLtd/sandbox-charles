# Teacher history compatibility diagnostic

Read the [protocol](../../../docs/plans/teacher-history-compatibility.md) and
[results](../../../docs/plans/teacher-history-compatibility-results.md) first.
This does not train or alter the demo.

Use an Apple-silicon Python environment with MLX 0.31.2, NumPy 2.5.4,
ONNX 1.23.2 and ONNX Runtime 1.31.1. Plotting additionally needs Matplotlib.
Set `A2F_RESEARCH_WORK` to the existing research asset workspace and
`A2F_TEACHER_ROOT` to the original repository's `ai-workflows/apple-silicon`.
`common.py` documents the expected asset layout and pins the baseline SHA.
Existing compact-scale corpus manifests/audio, compact-feature control export,
arkit-student rig metrics and full James teacher assets are required. These are
large ignored artifacts, not downloaded or generated by this diagnostic.

From the app directory, in order:

```sh
python scripts/research/teacher_history/prepare.py
python scripts/research/teacher_history/run.py
python scripts/research/teacher_history/summarize.py
python scripts/research/teacher_history/decompose.py
python scripts/research/teacher_history/plot.py
python scripts/research/teacher_history/test_analysis.py
```

`prepare.py` freezes the input streams, source hashes and analysis into
`.local/teacher-history-v1`; `run.py` verifies original-teacher parity and runs
factorial/repeat/reset controls. Hash and equality failures stop execution.
`summarize.py` computes primary pairwise metrics, `decompose.py` is supplementary
conditional-MSE analysis, and `plot.py` generates decay/voice figures and engine
breakdowns. `A2F_HISTORY_OUTPUT` selects a separate output directory. Reuse the
same output only with identical inputs/code; frozen artifact writes refuse
changed contents. Completion includes wall time, so a fresh rerun should use a
fresh output directory. Do not edit frozen primary analysis after viewing results.
The checked-in report retains the results; local JSON/arrays/plots remain ignored.
